# 线性基

### 1\. 什么是线性基？

想象一下，你有一堆数字（一个集合 S）。你对这些数字最感兴趣的操作是**异或（XOR）**。你想要知道：

-   从这堆数字里随便选几个，异或起来，能得到哪些新的数字？
    
-   在所有这些能得到的数字中，最大的是多少？
    
-   某个特定的数 `X` 能不能被异或出来？
    
-   在所有能得到的数字中，第 k 大的是多少？
    

线性基就是一个能够高效解决以上所有问题的数据结构。

**一句话定义：** 线性基是原始集合 S 的一个**最小化**的子集 B，它与原集合 S 有着相同的“异或张成空间”。也就是说，原集合 S 能异或出的任何数，都可以通过线性基 B 中的元素异或出来，反之亦然。

可以把它类比成线性代数中的**基（Basis）**。在线性空间中，一组基向量可以通过线性组合（加法和数乘）张成整个空间。在线性基中，这组“基向量”就是线性基里的数字，而“线性组合”就是**异或运算**。

### 2\. 线性基的构造（核心操作：插入）

线性基最核心的操作就是 `insert(x)`，即向基中插入一个数 `x`。它的构造过程非常巧妙，利用了异或的性质。

我们通常用一个数组 `p[]` 来表示线性基，其中 `p[i]` 存储的是一个“基向量”，这个基向量的\*\*最高位（Most Significant Bit, MSB）\*\*恰好是第 `i` 位。如果 `p[i] = 0`，说明我们还没有一个最高位是 `i` 的基。

**插入过程** `insert(x)`**：**

我们从高位到低位遍历 `x` 的二进制表示（例如，从第 62 位到第 0 位，对于 `long long` 类型）。

1.  检查 `x` 的第 `i` 位是否为 1。
    
2.  如果第 `i` 位是 0，我们就不关心这一位，继续看下一位（`i-1`）。
    
3.  如果第 `i` 位是 1，这时有两种情况：
    
    -   **情况A：**`p[i]` **为 0。** 这意味着我们找到了一个新的、无法被现有基表示的“方向”。我们就让 `p[i] = x`，然后**直接结束插入过程**。因为 `x` 已经被成功地加入到基中，成为了一个新的基向量。
        
    -   **情况B：**`p[i]` **不为 0。** 这意味着我们已经有一个最高位为 `i` 的基向量 `p[i]`。为了消去 `x` 的第 `i` 位，我们执行 `x = x XOR p[i]`。这样操作后，新的 `x` 的第 `i` 位必然为 0，并且它的最高位变得比 `i` 更低了。我们继续用这个新的、更小的 `x` 去尝试插入到更低的位。
        
4.  如果遍历完所有位，`x` 变成了 0，这意味着 `x` 完全可以由现有的基向量异或表示出来，我们不需要做任何事，插入过程结束。
    

**代码实现 (C++)**

```cpp
long long p[64]; // 线性基数组

void insert(long long x) {
    // 从高位到低位遍历
    for (int i = 62; i >= 0; i--) {
        // 如果 x 的第 i 位是 0，跳过
        if (!(x >> i & 1)) continue;

        // 如果 p[i] 为 0，说明找到了新的基
        if (!p[i]) {
            p[i] = x;
            return; // 成功插入，结束
        }
        
        // 如果 p[i] 不为 0，用它来消去 x 的第 i 位
        x ^= p[i];
    }
    // 如果循环结束 x 变成了 0，说明 x 可以被现有的基表示
}
```

### 3\. 线性基的性质

构造好的线性基具有一些非常美妙的性质：

1.  **等价性**：原集合 S 中的任何数，都可以由线性基 B 中的若干个数异或得到。
    
2.  **无关性**：线性基 B 中任何非空子集的异或和都不为 0。这是它“线性无关”的体现。
    
3.  **最优性**：线性基是满足性质1的最小集合。
    
4.  **贪心友好**：经过高斯消元处理后的线性基，其 `p[i]` 的第 `i` 位为 1，但其更高位（j > i）都为 0，这为求第 k 大值提供了便利。
    

### 4\. 线性基的应用

#### 应用一：查询一个数 `X` 能否被异或出来

这和插入操作几乎一样。我们尝试用线性基去“约简” `X`。

```cpp
bool can_be_represented(long long x) {
    for (int i = 62; i >= 0; i--) {
        if (!(x >> i & 1)) continue;
        if (!p[i]) return false; // 无法消去这一位，说明不能被表示
        x ^= p[i];
    }
    return true; // 如果最终 x 变成 0，说明可以被表示
}
```

#### 应用二：查询最大异或和

这是最经典的应用。我们想让结果的尽可能高的位为 1。

**贪心策略：** 从最高位向最低位遍历。对于当前结果 `ans`，如果 `ans` 异或上 `p[i]` 能使 `ans` 变得更大，我们就执行这个异或。

```cpp
long long query_max() {
    long long ans = 0;
    for (int i = 62; i >= 0; i--) {
        // 核心思想：如果 ans 的第 i 位为 0，我们希望用 p[i] 把它变成 1
        // 等价于 ans ^ p[i] > ans
        if ((ans ^ p[i]) > ans) {
            ans ^= p[i];
        }
    }
    return ans;
}
```

#### 应用三：查询最小异或和（非0）

如果原集合可以异或出 0（即插入时有数字变成了0），那么最小异或和就是 0。否则，最小非零异或和就是线性基中最小的那个元素。通常，我们只需要找到第一个 `p[i]` 不为0的 `p[i]` 即可。

```cpp
long long query_min() {
    for (int i = 0; i <= 62; i++) {
        if (p[i]) {
            return p[i];
        }
    }
    return 0; // 如果线性基是空的
}
```

#### 应用四：查询第 k 大异或和（高级）

这是一个更复杂但非常强大的应用。

1.  **预处理线性基**：对现有的 `p[]` 数组进行一次**高斯消元**，使其成为一个“三角矩阵”。目标是让 `p[i]` 的第 `j` 位为1当且仅当 `i == j`。
    
    ```cpp
    void gaussian_elimination() {
        for (int i = 62; i >= 0; i--) {
            if (p[i]) {
                for (int j = i - 1; j >= 0; j--) {
                    // 如果 p[j] 的第 i 位也为 1，就用 p[i] 消去它
                    if (p[j] >> i & 1) {
                        p[j] ^= p[i];
                    }
                }
            }
        }
    }
    ```
    
2.  **构建最终基向量**：将所有非零的 `p[i]` 放入一个新的数组 `d[]` 中，这个数组的长度就是基的大小，记为 `cnt`。
    
3.  **查询**：
    
    -   总共能异或出 `2^cnt` 个不同的数。
        
    -   将 `k` 进行二进制拆分。如果 `k` 的第 `j` 位是 1，就将答案异或上 `d[j]`（假设 `d` 是从低位基到高位基排序的）。
        

```cpp
long long query_kth(long long k) {
    // 假设已经执行了高斯消元
    vector<long long> d;
    for (int i = 0; i <= 62; i++) {
        if (p[i]) d.push_back(p[i]);
    }
    
    // 特殊情况：如果原集合可以异或出0，那么k=1时应返回0。
    // 这需要判断线性基的大小是否小于原集合的元素个数。
    // 这里简化处理，假设查询的是第k大非零值。
    
    long long ans = 0;
    if (k >= (1LL << d.size())) return -1; // k 超出范围

    for (int i = 0; i < d.size(); i++) {
        if (k >> i & 1) {
            ans ^= d[i];
        }
    }
    return ans;
}
```

### 总结

线性基是一个处理集合异或问题的强大工具，它通过构造一组“正交”的基向量，将复杂的子集异或问题转化为简单的贪心或位运算问题。它的核心是 `insert` 操作，理解了这个，其他应用也就水到渠成了。
