# int128

简单来说，`__int128` 是 C++ 中的一种“超级整数”类型。

### 1\. 它是干什么用的？

在 C++ 中，我们常用的整数类型有：

-   `int`：占用 4 字节（32 位），最大约 $2 \times 10^9$。
    
-   `long long`：占用 8 字节（64 位），最大约 $9 \times 10^{18}$。
    

但是，在处理数论（如你刚才发的那道题）或大数运算时，我们经常会遇到 这种级别的计算。

-   这已经远远超过了 `long long` 的极限。这时候，如果你不想写繁琐的“高精度模拟”算法（用数组模拟数字），`__int128` 就是最简单的选择。
    

### 2\. 它的具体数值范围

`__int128` 占用 **16 字节（128 位）**：

-   **最大值**：$2^{127} - 1 \approx 1.7 \times 10^{38}$。
    
-   **位数**：它能精确存储最多 **38位** 左右的十进制整数。
    
-   **无符号版本**：`unsigned __int128` 最大可达 $3.4 \times 10^{38}$。
    

### 3\. 兼容性（重点！）

-   **GCC / Clang**：完全支持。在几乎所有的算法竞赛平台（Codeforces, LeetCode, 蓝桥杯, 各种 OJ）上，只要使用 G++ 编译器，都能直接用。
    
-   **Visual Studio (MSVC)**：**不支持**。如果你在本地用 VS 刷题，编译器会报错。建议本地使用 VS Code + GCC 插件。
    
-   **非标准**：它不是 C++ 标准定义的类型，所以它是以 `__`（双下划线）开头的。
    

### 4\. 如何使用（输入输出）

这是 `__int128` 唯一的弱点：`std::cin` **和** `std::cout` **无法直接识别它。** 你不能直接写 `cin >> a;`。你需要手写输入输出函数。

**示例代码：**

```cpp
#include <iostream>
using namespace std;

typedef __int128_t int128; // 给它起个简短的别名

// 手写快读：处理输入
int128 read() {
    int128 x = 0;
    long long t;
    if (cin >> t) x = t; // 很多时候可以先读入 long long 再赋值给 int128
    return x;
}

// 手写输出：递归打印每一位
void print(int128 x) {
    if (x < 0) { putchar('-'); x = -x; }
    if (x > 9) print(x / 10);
    putchar(x % 10 + '0');
}

int main() {
    // 两个 $10^{18}$ 级别的数字相乘
    int128 a = 1000000000000000000LL; // 1e18
    int128 b = 1000000000000000000LL; // 1e18
    int128 c = a * b; // 结果 1e36，long long 会爆，但 int128 稳如老狗
    
    print(c); // 输出：1000000000000000000000000000000000000
    return 0;
}
```
