# 扩展欧几里得算法

### 第一层：数学推导（为什么能求出 x 和 y？）

扩展欧几里得的核心在于：**利用“递归”的思想，通过下一层的解来推导当前层的解。**

#### 1\. 基本欧几里得（找 GCD）

我们知道： $\gcd(a, b) = \gcd(b, a \bmod b)$。这是辗转相除法的核心。

#### 2\. 裴蜀等式（寻找联系）

我们要找一对 $(x, y)$使得：

$$ax + by = \gcd(a, b)$$

假设我们在下一层递归中（即处理 $b$和 $a \bmod b$时），已经求出了一组解 $(x_1, y_1)$，满足：

$$b \cdot x_1 + (a \bmod b) \cdot y_1 = \gcd(b, a \bmod b)$$

因为 $\gcd(a, b) = \gcd(b, a \bmod b)$，所以：

$$b \cdot x_1 + (a \bmod b) \cdot y_1 = \gcd(a, b)$$

#### 3\. 展开与合并

我们知道取模运算的本质是： $a \bmod b = a - \lfloor a/b \rfloor \cdot b$（这里的 $\lfloor a/b \rfloor$是 C++ 中的整数除法 `a/b`）。

把这个式子代入上面的方程：

$$b \cdot x_1 + (a - \lfloor a/b \rfloor \cdot b) \cdot y_1 = \gcd(a, b)$$

展开括号：

$$b \cdot x_1 + a \cdot y_1 - \lfloor a/b \rfloor \cdot b \cdot y_1 = \gcd(a, b)$$

把含有 $a$的项和含有 $b$的项分别提取出来：

$$a \cdot (y_1) + b \cdot (x_1 - \lfloor a/b \rfloor \cdot y_1) = \gcd(a, b)$$

#### 4. 对比系数

对比最原始的式子 $ ax + by = \gcd(a, b) $ ，我们惊喜地发现：

- **当前层的 $ x = y_1 $**
- **当前层的 $ y = x_1 - \lfloor a/b \rfloor \cdot y_1 $**

**结论**：只要我们有了下一层的解 $ (x_1, y_1) $ ，就能算出当前层的解 $ (x, y) $ 。

### 第二层：手工模拟（走一遍流程）

求 $11x + 3y = \gcd(11, 3)$的一组解。（已知 $\gcd(11, 3) = 1$）

1.  **第一层**： $a = 11, b = 3$。等待下一层返回结果。
    
2.  **第二层**： $a = 3, b = 11 \bmod 3 = 2$。等待下一层。
    
3.  **第三层**： $a = 2, b = 3 \bmod 2 = 1$。等待下一层。
    
4.  **第四层**： $a = 1, b = 2 \bmod 1 = 0$。**到达边界！**
    
    -   根据 $1 \cdot x + 0 \cdot y = 1$，令 $x = 1, y = 0$。
        
    -   返回 $(x=1, y=0)$给第三层。
        
5.  **回到第三层**（ $a = 2, b = 1$）：
    
    -   此时下一层的 $x_1 = 1, y_1 = 0$。
        
    -   当前层 $x = y_1 = 0$。
        
    -   当前层 $y = x_1 - (2/1) \cdot y_1 = 1 - 2 \cdot 0 = 1$。
        
    -   返回 $(x=0, y=1)$给第二层。验证下： $2(0) + 1(1) = 1$，正确。
        
6.  **回到第二层**（ $a = 3, b = 2$）：
    
    -   此时下一层的 $x_1 = 0, y_1 = 1$。
        
    -   当前层 $x = y_1 = 1$。
        
    -   当前层 $y = x_1 - (3/2) \cdot y_1 = 0 - 1 \cdot 1 = -1$。
        
    -   返回 $(x = 1, y = -1)$给第一层。验证下： $3(1) + 2(-1) = 1$，正确。
        
7.  **回到第一层**（ $a = 11, b = 3$）：
    
    -   此时下一层的 $x_1 = 1, y_1 = -1$。
        
    -   当前层 $x = y_1 = -1$。
        
    -   当前层 $y = x_1 - (11/3) \cdot y_1 = 1 - 3 \cdot (-1) = 4$。
        
    -   **最终解： $x = -1, y = 4$** 。
        
    -   验证： $11 \cdot (-1) + 3 \cdot 4 = -11 + 12 = 1$。**完美！**

### 第三层：代码技巧（那个神奇的交换）

你经常会看到这样的 C++ 简洁写法：

```cpp
long long exgcd(long long a, long long b, long long &x, long long &y) {
    if (b == 0) {
        x = 1; y = 0;
        return a;
    }
    long long d = exgcd(b, a % b, y, x); // 神来之笔：y 和 x 调换了位置
    y -= (a / b) * x;
    return d;
}
```

**为什么这里交换了** `x` **和** `y`**？** 注意看 `exgcd(b, a % b, y, x)` 这一行：

-   在这一层里，我们把 `y` 传给了下一层的 `x`，把 `x` 传给了下一层的 `y`。
    
-   根据推导：当前层的 $x = y_{next}$。由于我们把当前层的 `x` 传到了下一层的 `y` 位置，递归回来时，`x` 已经自动变成了 $y_{next}$的值！
    

所以我们只需要手动更新 `y`：`y = y_old - (a/b) * x_new`。

-   这里的 `y_old` 是传进去之前的 `x`（即下一层的 $x_1$）。
    
-   这里的 `x_new` 是递归回来后的 `x`（即下一层的 $y_1$）。

### 扩展欧几里得有什么用？

#### 1\. 求逆元（最常用）

在模运算中，没有除法。如果你想算 $(a / b) \bmod m$，你需要找到 $b$的逆元 $inv$。 $inv$满足 $b \cdot inv \equiv 1 \pmod m$。

这等价于方程： $b \cdot inv + m \cdot k = 1$。

用 `exgcd(b, m, inv, k)` 就能求出 $inv$。

#### 2\. 求解不定方程$ax + by = c$

-   先用 `exgcd` 求出 $ax_0 + by_0 = \gcd(a, b)$。
    
-   如果 $c$不是 $\gcd(a, b)$的倍数，方程无整数解。
    
-   如果是倍数，将 $x_0, y_0$同时扩大 $c / \gcd(a, b)$倍即可得到一组特解。
    
-   **通解公式**： $x = x_{base} + k \cdot \frac{b}{\gcd(a, b)}$。这可以用来求最小正整数解。
