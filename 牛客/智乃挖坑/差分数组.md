# 差分数组（Difference Array）

## 零、 核心思想速览

-   **前缀和**：用于解决 $O(1)$的**区间求和**问题。
    
-   **一阶差分**：用于解决 $O(1)$的**区间加减常数**问题。
    
-   **二阶差分**：用于解决 $O(1)$的**区间加减等差数列**问题。
    
-   **本质关系**：差分与前缀和互为**逆运算**（类似于求导与积分）。
    

---

## 一、 基础阶段：一阶差分数组

### 1\. 什么是差分数组？

假设有一个原数组 $A$（下标从 $1$开始），我们定义一个新数组 $D1$，使得 $D1$中的每一项等于 $A$中相邻两项的差。 **定义式：** $D1[i] = A[i] - A[i-1]$（通常规定 $A[0] = 0$）

**举例：**

-   原数组 $A$：`[0, 3, 5, 8, 8, 10]`
    
-   差分数组 $D1$：`[0, 3, 2, 3, 0, 2]` *(例如 $D1[2] = 5-3=2$)*
    

### 2\. 差分数组的“还原”性质

如果我们只知道差分数组 $D1$，如何求出原数组 $A$中的某个值？ **结论：原数组 $A$是差分数组 $D1$的前缀和。** 公式推导：$A[x] = (A[x] - A[x-1]) + (A[x-1] - A[x-2]) + \dots + (A[1] - A[0])$$A[x] = D1[x] + D1[x-1] + \dots + D1[1] = \sum_{i=1}^x D1[i]$

### 3\. 一阶差分的核心应用：区间加减操作

**场景**：给原数组 $A$的区间 $[L, R]$内的每个元素都加上一个常数 $V$。 如果直接在 $A$上遍历修改，时间复杂度为 $O(N)$。

**利用差分优化**： 思考一下，如果 $A[L \dots R]$全部变大了 $V$，它们内部相邻元素之间的**差值**改变了吗？没有！ 唯一发生改变的是区间的**两端**：

1.  **左端点 $L$** ：$A[L]$ 变大了 $V$，而 $A[L-1]$没变，所以它们的差值变大了 $V$。$\rightarrow \mathbf{D1[L] += V}$
    
2.  **右端点的后一个位置 $R+1$** ：$A[R+1]$ 没变，而 $A[R]$变大了 $V$，所以它们的差值变小了 $V$。$\rightarrow \mathbf{D1[R+1] -= V}$
    

**代码模板：**

```cpp
// 1. 对差分数组进行 O(1) 的修改
void add_constant(vector<int>& D1, int L, int R, int V) {
    D1[L] += V;
    D1[R + 1] -= V;
}

// 2. 所有操作结束后，O(N) 还原原数组
void restore_array(vector<int>& A, const vector<int>& D1) {
    int current_sum = 0;
    for(int i = 1; i < D1.size(); i++) {
        current_sum += D1[i];
        A[i] = current_sum;
    }
}
```

## 二、 进阶阶段：二阶差分数组（深度解析）

### 1\. 为什么需要二阶差分？

**场景**：给原数组 $A$的区间 $[L, R]$加上一个**等差数列**。 例如：给 $[L, R]$依次加上 $V, V+d, V+2d, \dots$（首项为 $V$，公差为 $d$）。 如果用一阶差分，区间内的差值不再是不变的，这意味着一阶差分数组 $D1$在区间 $[L, R]$内需要被加上一连串常数（即区间加常数 $d$）。 为了把对 $D1$的“区间加常数”操作优化为 $O(1)$，我们**对 $D1$再做一次差分，建立二阶差分数组 $D2$** 。

### 2\. 理论推导与公式

已知：

-   $A$为原数组。
    
-   $D1[i] = A[i] - A[i-1]$（一阶差分）
    
-   $D2[i] = D1[i] - D1[i-1]$（二阶差分）
    

我们要在 $A$的区间 $[L, R]$加上首项为 $V$，公差为 $d$的等差数列。末项设为 $E = V + (R-L) \times d$。 观察原数组的变化量 $\Delta A$：$\Delta A[L] = V$$\Delta A[L+1] = V + d$$\dots$$\Delta A[R] = E$

推导一阶差分的变化量 $\Delta D1 = \Delta A[i] - \Delta A[i-1]$：

1.  在位置 $L$：$\Delta D1[L] = V - 0 = \mathbf{V}$
    
2.  在区间 $[L+1, R]$：相邻两项相减总是公差 $d$。$\Delta D1[L+1 \dots R] = \mathbf{d}$
    
3.  在位置 $R+1$：$\Delta D1[R+1] = 0 - E = \mathbf{-E}$
    

现在，推导二阶差分的变化量 $\Delta D2 = \Delta D1[i] - \Delta D1[i-1]$：

1.  **位置 $L$** ：$\Delta D2[L] = \Delta D1[L] - 0 = \mathbf{V}$
    
2.  **位置 $L+1$** ：$\Delta D2[L+1] = \Delta D1[L+1] - \Delta D1[L] = \mathbf{d - V}$
    
3.  **位置 $R+1$** ：$\Delta D2[R+1] = \Delta D1[R+1] - \Delta D1[R] = -E - d = \mathbf{-(E + d)}$
    
4.  **位置 $R+2$** ：$\Delta D2[R+2] = 0 - \Delta D1[R+1] = 0 - (-E) = \mathbf{E}$
    

**🌟 核心结论：给区间加上等差数列，只需要在二阶差分数组 $D2$上修改 4 个点！**

### 3\. 具体例子验证

假设数组长度足够长，我们要在区间 `[2, 5]` 上加上等差数列 `1, 2, 3, 4`。 此时参数为：$L=2,\ R=5,\ V=1,\ d=1,\ E=4$。

按照上面推导的 4 点修改法，操作 $D2$：

所以修改后的$\Delta D2 = [0, 0, \mathbf{1}, \mathbf{0}, 0, 0, \mathbf{-5}, \mathbf{4}, 0, \dots]$

**验证还原过程（求两次前缀和）：** 第一次前缀和，求出 $\Delta D1$： $\Delta D1[2] = 1$$\Delta D1[3] = 1+0 = 1$$\Delta D1[4] = 1+0 = 1$$\Delta D1[5] = 1+0 = 1$$\Delta D1[6] = 1-5 = -4$$\Delta D1[7] = -4+4 = 0$（一阶差分数组变成了：第2项突增1，3~5项持续加公差1，第6项骤降补偿）

第二次前缀和，求出 $\Delta A$： $\Delta A[2] = 1$$\Delta A[3] = 1+1 = 2$$\Delta A[4] = 2+1 = 3$$\Delta A[5] = 3+1 = 4$$\Delta A[6] = 4-4 = 0$（完美还原！我们成功地在原数组的 2~5 位置加上了 `1, 2, 3, 4`）

### 4\. 二阶差分代码模板

```cpp
#include <vector>

using namespace std;

// 1. O(1) 时间内加上等差数列
// 参数: 二阶差分数组 D2, 区间左端点 L, 右端点 R, 首项 V, 公差 d
void add_arithmetic_progression(vector<long long>& D2, int L, int R, long long V, long long d) {
    long long E = V + (R - L) * d; // 计算末项
    
    D2[L]     += V;
    D2[L + 1] += d - V;
    D2[R + 1] -= E + d;
    D2[R + 2] += E;
}

// 2. O(N) 还原原始数组 A
void restore_from_D2(vector<long long>& A, const vector<long long>& D2) {
    int n = A.size() - 1; 
    
    long long current_D1 = 0; // 记录一阶差分的当前前缀和
    long long current_A = 0;  // 记录原数组的当前前缀和
    
    for (int i = 1; i <= n; i++) {
        current_D1 += D2[i];      // 第一次前缀和：还原出 D1
        current_A += current_D1;  // 第二次前缀和：还原出 A
        A[i] += current_A;        // 叠加到真实的 A 数组上
    }
}
```

## 三、 总结与记忆口诀

| 操作目标 | 适合的数据结构 | $O(1)$ | 还原时间 |
| --- | --- | --- | --- |
| **单点修改** | $A$ | `A[i] += V` | 不需还原 |
| **区间求和** | $S$ | `S[R] - S[L-1]` | $O(N)$ |
| **区间加减固定值** | $D1$ | $L,\ R+1$ | $O(N)$ |
| **区间加减等差数列** | $D2$ | $L,\ L+1,\ R+1,\ R+2$ | $O(N)$ |

**记忆核心**：每一次向上的“区间批量修改”，都可以通过“求导（差分）”降维打击，将操作范围缩小至区间的边界点；最后再通过“积分（前缀和）”把结果还原。
