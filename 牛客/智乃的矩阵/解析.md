# 智乃的矩阵

## 🤖 Assistant

这题不要去模拟操作，关键是找 **不变量**。

题目操作是在一个 $2 \times 2$ 子矩阵里选两对相邻且不重叠的数，一对都 $+1$，另一对都 $-1$。

比如一个 $2 \times 2$：

```vbnet
a b
c d
```

可以有两类操作：

### 横着选两对

```vbnet
a b   +1 +1
c d   -1 -1
```

或者反过来：

```vbnet
a b   -1 -1
c d   +1 +1
```

### 竖着选两对

```vbnet
a b   +1 -1
c d   +1 -1
```

或者反过来：

```vbnet
a b   -1 +1
c d   -1 +1
```

我们要判断能不能把整个矩阵变成同一个数。

# 一、最终的数一定是什么？

假设最后所有数都变成了 $x$。

矩阵一共有 $n^2$ 个数，所以最后总和是：

$$
n^2 \times x
$$

每次操作都是两个数 $+1$，两个数 $-1$，所以总和不变。

因此初始矩阵总和 $sum$ 必须满足：

$$
sum = n^2 \times x
$$

所以：

$$
x = \frac{sum}{n^2}
$$

因此第一步：

```cpp
if (sum % (n * n) != 0) No
```

否则目标值就是：

```cpp
x = sum / (n * n)
```

# 二、第一个不变量：黑白格总和

把矩阵像国际象棋棋盘一样染色：

```vbnet
黑 白 黑 白 ...
白 黑 白 黑 ...
黑 白 黑 白 ...
...
```

也就是：

```cpp
if ((i + j) % 2 == 0) 是黑格
else 是白格
```

观察一次操作对黑白格的影响。

以 $2 \times 2$ 为例：

```vbnet
黑 白
白 黑
```

如果做横向操作：

```vbnet
黑 白    +1 +1
白 黑    -1 -1
```

黑格变化：

```vbnet
左上黑格 +1
右下黑格 -1
```

所以黑格总和不变。

白格变化：

```vbnet
右上白格 +1
左下白格 -1
```

所以白格总和也不变。

竖向操作同理。

所以：

> 
> 
> 
> 黑格总和不变，白格总和不变。
> 

如果最后所有数都变成 $x$，那么：

```cpp
黑格总和 = 黑格数量 * x
白格总和 = 白格数量 * x
```

所以必须满足：

```cpp
blackSum == blackCnt * x
whiteSum == whiteCnt * x
```

否则答案是 `No`。

# 三、第二个不变量：每一行、每一列的和的奇偶性

再看每次操作对行和、列和的影响。

## 1. 横向操作

例如：

```vbnet
+1 +1
-1 -1
```

第一行的和增加了：

```vbnet
+1 + +1 = +2
```

第二行的和减少了：

```vbnet
-1 + -1 = -2
```

所以行和只会变化偶数，行和奇偶性不变。

而每一列：

```vbnet
第一列：+1 + -1 = 0
第二列：+1 + -1 = 0
```

列和根本不变。

## 2. 竖向操作

例如：

```vbnet
+1 -1
+1 -1
```

每一行：

```vbnet
+1 + -1 = 0
```

行和不变。

第一列：

```vbnet
+1 + +1 = +2
```

第二列：

```vbnet
-1 + -1 = -2
```

列和只会变化偶数，列和奇偶性不变。

所以结论是：

> 
> 
> 
> 每一行的和的奇偶性不变，每一列的和的奇偶性也不变。
> 

如果最后所有数都变成 $x$，那么每一行的和都是：

$$
n \times x
$$

每一列的和也是：

$$
n \times x
$$

所以初始矩阵中：

```cpp
每一行的和 % 2 必须等于 (n * x) % 2
每一列的和 % 2 必须等于 (n * x) % 2
```

否则答案是 `No`。

# 四、判断条件总结

这题最后只需要检查 3 类条件：

1. 总和能不能被 $n^2$ 整除；
2. 黑/白格总和是否等于 `黑/白格数量 * x`；
3. 每一行、每一列的和的奇偶性是否等于 `(n * x) % 2`。

全部满足就是 `Yes`，否则 `No`。

这些条件不仅是必要的，也是充分的，也就是说：只要这些条件都满足，就一定可以通过若干次操作变成全相等。

# 五、充分性证明

## 1. 先把目标值减掉

假设最终所有数都要变成：

$$
x
$$

我们把每个位置都减去 x，得到一个新矩阵：

$$
b_{i,j}=a_{i,j}-x
$$

那么问题就变成：

> 
> 
> 
> 能不能通过操作，把整个 b 矩阵变成全 0？
> 

因为如果 b 全部变成 0，就说明原矩阵全部变成了 x。

## 2. 那些条件在新矩阵里变成什么？

前面说的条件如果成立，那么对于新矩阵 b，有：

### 条件 1：总和为 0

$$
\sum b_{i,j}=0
$$

### 条件 2：棋盘染色和为 0

$$
\sum (-1)^{i+j}b_{i,j}=0
$$

这等价于：

> 
> 
> 
> 黑格子的总和 = 白格子的总和
> 

又因为总和为 0，所以：

$$
黑格总和=0,\quad 白格总和=0
$$

### 条件 3：每一行、每一列的和都是偶数

因为目标矩阵减掉以后，每行每列和的奇偶性都应该变成偶数。

所以现在我们要证明：

> 
> 
> 
> 如果一个矩阵满足：
> 
> 1. 总和为 0；
> 2. 黑格总和为 0，白格总和为 0；
> 3. 每行、每列和都是偶数；
> 
> 那么它一定可以被操作变成全 0。
> 

这就是充分性的核心。

## 3. 操作能做什么？

考虑一个 `2 × 2` 小块：

$$
\begin{matrix}
a & b\\
c & d
\end{matrix}
$$

操作有两类本质效果。

### 第一类：上面两个加，下面两个减

$$
\begin{matrix}
+1 & +1\\
-1 & -1
\end{matrix}
$$

### 第二类：左边两个加，右边两个减

$$
\begin{matrix}
+1 & -1\\
+1 & -1
\end{matrix}
$$

现在把这两种操作相加:

```math
\begin{aligned}
\begin{pmatrix} +1 & +1 \\ -1 & -1 \end{pmatrix}
+
\begin{pmatrix} +1 & -1 \\ +1 & -1 \end{pmatrix}
=
\begin{pmatrix} +2 & 0 \\ 0 & -2 \end{pmatrix}
\end{aligned}
```

也就是说，我们可以做到:

```math
\begin{matrix}
+2 & 0\\
0 & -2
\end{matrix}
```


这表示：

> 
> 
> 
> 可以在同颜色的两个对角格子之间转移 2。
> 

比如：

$$
\begin{matrix}
\color{red}{+2} & 0\\
0 & \color{red}{-2}
\end{matrix}
$$

这两个对角格颜色相同。

同理，两种操作相减：

```math
\begin{matrix}
+1 & +1\\
-1 & -1
\end{matrix}
-
\begin{matrix}
+1 & -1\\
+1 & -1
\end{matrix}
=
\begin{matrix}
0 & +2\\
-2 & 0
\end{matrix}
```

也可以在另一组同色对角格之间转移 2。

所以结论是：

> 
> 
> 
> 我们可以在任意两个相邻对角的同色格子之间，搬运数量 2。
> 

## 4. 第一步：先把所有数变成偶数

为什么可以做到？

注意一次操作中，每个被选中的格子都会加减 1。

从奇偶性角度看：

$$
+1 \equiv -1 \equiv 1 \pmod 2
$$

所以无论是加 1 还是减 1，本质都是翻转这个数的奇偶性。

一次操作会翻转某个 `2 × 2` 小矩阵中四个数的奇偶性。

也就是说，我们可以做这种事情：

$$
\begin{matrix}
翻转 & 翻转\\
翻转 & 翻转
\end{matrix}
$$

现在问题变成：

> 
> 
> 
> 如果每行、每列的奇偶和都是偶数，能不能通过翻转若干个 `2 × 2` 小块，把所有格子都变成偶数？
> 

答案是可以。

### 举个消元思路

从左上角开始扫。

如果当前位置是奇数，就对它右下方的 `2 × 2` 小块操作一次，把它变成偶数。

比如处理位置 (i,j)，如果它是奇数，就操作这个块：

$$
\begin{matrix}
(i,j) & (i,j+1)\\
(i+1,j) & (i+1,j+1)
\end{matrix}
$$

这样当前位置的奇偶性会被翻转，变成偶数。

从左到右、从上到下处理到前 (n-1) 行、前 (n-1) 列。

最后剩下最后一行和最后一列。

由于每一行、每一列的奇偶和本来就是偶数，所以最后一行和最后一列也会自动变成偶数。

因此：

> 
> 
> 
> 只要每行、每列和都是偶数，就可以通过操作让所有元素都变成偶数。
> 

## 5. 第二步：所有数都是偶数后，把它们清零

现在矩阵里的数全是偶数。

我们刚才已经知道，可以在同色格子之间搬运 2。

比如同色格子 u 和 v，可以让：

$$
u += 2,\quad v -= 2
$$

或者反过来。

### 关键点：同色格子之间是连通的

棋盘上所有黑格之间，可以通过斜着走连接起来。

例如：

$$
(1,1)\to(2,2)\to(1,3)
$$

都是同色格。

白格同理。

所以：

> 
> 
> 
> 任意两个黑格之间，都可以通过若干次对角转移，把 2 从一个格子搬到另一个格子；
> 
> 任意两个白格之间也一样。
> 

## 6. 为什么能清零黑格？

因为黑格总和是 0。

所有黑格上的数又都是偶数。

选一个黑格当仓库，比如左上角某个黑格。

然后对其他每个黑格：

- 如果它是正数，就把它的值搬到仓库；
- 如果它是负数，就从仓库搬一些值给它；

由于每次可以搬 2，而所有数都是偶数，所以一定能搬干净。

最后，其他黑格都变成 0。

因为黑格总和本来就是 0，所以仓库那个黑格也一定变成 0。

白格同理。

## 7. 整体过程总结

满足不变量后，新矩阵 b=a-x 有：

1. 总和为 0；
2. 黑格总和为 0，白格总和为 0；
3. 每行、每列和都是偶数。

然后：

### 第一步

利用 `2 × 2` 操作翻转奇偶性，把所有数都变成偶数。

### 第二步

利用两个基础操作组合：

$$
\begin{matrix}
+2 & 0\\
0 & -2
\end{matrix}
$$

和

$$
\begin{matrix}
0 & +2\\
-2 & 0
\end{matrix}
$$

在同色格子之间转移 2。

因为黑格总和为 0，所以黑格可以清零。

因为白格总和为 0，所以白格也可以清零。

最终整个矩阵变成全 0。

所以原矩阵就能变成全 (x)。

## 8. 直观理解

可以把整个证明想象成两步：

### 先解决奇偶性

每行、每列奇偶性对了，说明可以通过一些 `2 × 2` 操作，把所有数调成偶数。

### 再解决具体数值

所有数都是偶数以后，每次操作组合可以在同色格子之间搬运 2。

黑格内部总和为 0，白格内部总和也为 0，所以黑白两类格子都能自己内部消掉。

因此这些条件不只是必要的，也是充分的。
